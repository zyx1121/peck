# Peck identity

The canonical mark is `Peck.svg`: one rounded, concave wedge pointing right.
The inward cut suggests a beak and the outward point refers to selecting a page
element. Use the silhouette as a single-color UI mark, without lettering.

`Peck-material.png` gives the same outline depth, rounded edges, and an emerald
finish. Its pale blue-gray backdrop, visible left edge, upper-right key light,
and leftward shadow follow the [zyx Made series](https://www.zyx.tw/made).
`Peck.png` adds the macOS icon tile and transparent margin; `Peck.icns` packages
that icon for the application bundle.

The material artwork is rendered deterministically from the canonical SVG with
Three.js, not generated by an image model. The renderer and lighting are in
`scripts/brand-scene.ts`. Regenerate on the sandbox:

```sh
xvfb-run -a node scripts/render-brand.mjs
node scripts/icon.mjs
```

Normal builds use the committed material artwork and only regenerate the PNG
tile and ICNS container. The shell keeps the zyx signature in its corner and
uses Peck's geometric silhouette beside the product name.
